# 外字資料の調査結果

## 既存資料の概要
- **日本工業規格 (JIS) 補助漢字**: JIS X 0213 や JIS X 0208 に含まれない文字を収録。旧字・異体字を中心に公共機関で利用実績がある。
- **人名用漢字外字 (法務省)**: 戸籍統一文字情報データベース。住民基本台帳ネットワークで利用され、外字ID (例: `MJxxxx`) に対して Unicode 対応状況が整理されている。
- **Adobe-Japan1 コレクション**: DTP業界向けフォントセットで、多数の外字を CID ベースで管理。Unicode 変換表 (Adobe-Japan1-7) が公開されている。
- **IPA 外字対応表**: 独立行政法人 IPA が公開する地方公共団体向けの外字対策資料。IPA 外字番号と Unicode の暫定マッピングが付属。
- **東洋経済新報社 外字**: 出版社で運用されてきた独自外字。Unicode 対応表が公開されており、部首・字形情報も併記。
- **民間フォントベンダ (モリサワ, リコーなど)**: PUA (Private Use Area) を利用した文字割り当てを行い、コード体系と字形がドキュメント化されている。

## 暫定マッピング方針
1. 公的資料 (戸籍統一文字, IPA) を優先し、確定 Unicode が存在する場合はそれを採用。
2. Unicode 未収録の字形は PUA のうち `U+E000` 以降を暫定的に利用し、備考に由来資料を記録。
3. 出典が複数ある場合は最も利用頻度の高い字形を優先し、備考で異体字を列挙する。
4. 変換後に読み仮名や部首・画数が確認できるよう、メタデータを併用して辞書メンテナンス性を高める。

## 今後の拡張
- 既存の PDF/Excel 形式の外字リストをスクリプトで取り込み、SQLite データストアへ統合する。
- 変換精度向上のために、IPA 外字と MJ 文字の相互参照テーブルを構築する。
- 字形データ (SVG/ビットマップ) の保管場所を確保し、Web UI でプレビューできるようにする。
